# 产品需求文档（PRD）——《火柴人：怪物围城》

| 项 | 内容 |
|---|---|
| 项目代号 | monster_arena |
| 文档版本 | v0.6（Tiny Swords 开放海岛大地图 + 相机跟随；精灵伙伴系统；怪物攻击/受击动作全套启用） |
| 日期 | 2026-06-10 |
| 平台 | 桌面浏览器 + 手机浏览器（HTML5 Canvas，零依赖；本地双击即玩，线上链接即玩） |
| 类型 | 俯视角竞技场生存（survivor-like），单机单人 |

---

## 1. 一句话描述

主角（持枪火柴人）被困在竞技场中央，怪物从四周持续刷出并涌向主角；玩家用键盘（桌面）或虚拟摇杆（手机触屏）移动走位、朝向射击消灭怪物，活得越久、杀得越多分数越高；游戏部署在公网，把链接发给朋友即可游玩。

## 2. 背景与目标

- 复用 sprite_hero 项目（键盘控制帧动画 Demo）积累的主循环/输入/绘制经验，升级为一个**有完整游戏循环**（开始 → 战斗 → 死亡 → 重开）的可玩小游戏。
- 练手目标：怪物 AI、子弹与碰撞判定、刷怪节奏与难度曲线、HUD，全部用原生 Canvas 实现。
- P0 需求新增：手机触屏可玩（虚拟摇杆+攻击按钮）、部署到公网可通过链接分享游玩。
- 不做：联网对战/排行榜、账号系统、商业化。

## 3. 核心玩法循环

```
开始游戏
   ↓
怪物从场地四周持续刷出，朝主角移动
   ↓
玩家走位躲避 + 攻击怪物 ←——— 难度随时间上升（刷怪更快、怪更强）
   ↓
主角 HP 归零 → 结算界面（存活时间 / 击杀数 / 最高纪录）→ 一键重开
```

## 4. 详细需求

### 4.1 主角（P0）—— 持枪火柴人

| 属性 | 数值（MVP 初始值，可调） |
|---|---|
| 生命值 HP | 100 |
| 移动速度 | 240 px/s |
| 武器 | 手枪（MVP 唯一武器） |
| 子弹伤害 | 25 |
| 射速 | 4 发/秒（**全自动**，有敌人即开火） |
| 子弹速度 | 600 px/s，飞出屏幕即销毁 |
| 受击无敌 | 受击后 0.5s 无敌（闪烁表现） |

- 移动：方向键 / WASD，八方向自由移动，限制在场地边界内。
- **自动锁定与自动开火**：每帧锁定最近的存活怪物，枪口自动转向并按射速连发，玩家只负责走位（纯走位流，幸存者类标准手感）；无敌人时枪口跟随移动方向，不开火。
- 美术与动画：**代码矢量绘制火柴人**（圆头 + 线条躯干四肢 + 手持枪形），不依赖雪碧图：
  - 待机：站姿，枪随朝向指向
  - 走路：两腿交替摆动（2–4 个程序化关键姿态循环）
  - 射击：枪口火光（muzzle flash）+ 手臂后坐抖动
- 受击反馈：HP 扣减 + 角色闪红/闪烁 + 短暂击退（可选 P1）。
- 原小火龙雪碧图素材弃用，保留在 sprite_hero 项目中，本项目不再引用。

### 4.2 怪物（P0）

- **生成规则**：在屏幕可视范围之外的环形区域随机位置刷出（保证"从四周涌来"的感受，参考原型草图）；刷出类型按难度档位的权重表随机。
- **状态机**：move（追近/保持距离）→ attack（播放攻击动画，到 hitFrame 帧结算伤害）→ 冷却后再攻。**伤害全部通过攻击动作结算**，不再用纯碰撞扣血——怪物有明确的出手动作，玩家可以看预备动作躲避。
- **死亡**：HP 归零播放死亡动画后淡出，计入击杀数。
- **怪物图鉴**（已全部实装，luizmelo CC0 素材）：

| 类型 | 定位 | HP | 移速 | 伤害 | 攻击方式 |
|---|---|---|---|---|---|
| 哥布林 | 基础近战 | 50 | 120 | 10 | 贴脸弯刀挥击（1.0s 冷却） |
| 飞眼 | 高速冲锋 | 30 | 210 | 8 | 飞扑撕咬（0.8s 冷却，快） |
| 蘑菇怪 | 远程 | 40 | 80 | 12 | 280px 外停步吐**孢子弹**（230px/s，可走位躲开） |
| 骷髅 | 坦克 | 150 | 70 | 20 | 重剑挥砍（1.4s 冷却，高伤） |

- 出场节奏（难度权重）：0–30s 纯哥布林 → 30–60s 加入飞眼 → 60–120s 加入蘑菇/少量骷髅 → 120s+ 四类混合，骷髅占比升至 20%。

### 4.3 刷怪与难度曲线（P0）

- 以"游戏进行时间"驱动难度：

| 时间 | 刷怪间隔 | 同屏上限 | 怪物 HP 倍率 |
|---|---|---|---|
| 0–30s | 2.0s | 8 | ×1.0 |
| 30–60s | 1.2s | 15 | ×1.2 |
| 60–120s | 0.8s | 25 | ×1.5 |
| 120s+ | 0.5s | 40 | ×2.0（每 60s 再 +0.5） |

- 数值表抽成配置（JS 常量表），方便调参。

### 4.4 战斗判定（P0）

- 主角攻击：自动向最近敌人按射速发射子弹（小圆，r≈4px）；子弹与怪物圆-圆相交即命中，扣血+击退，子弹销毁（不穿透，穿透作为 P1 升级项）。
- 怪物伤害：近战怪攻击动画到 hitFrame 帧时，若主角仍在攻击范围内则结算伤害；远程怪在 hitFrame 帧朝主角当前位置发射孢子弹（带动画），孢子弹与主角圆-圆相交结算伤害后消失。
- 受击统一走无敌帧（0.5s），任何来源的伤害都不会连续秒杀。
- 同屏子弹上限 100（正常射速达不到）。
- 伤害数字飘字（P1）；击杀音效/受击音效（P2，可不做）。

### 4.5 成长系统（P0，已实装）—— 金币 / 经验 / 商城

**跨局持久化**（localStorage）：金币、经验等级、已购武器装备在局与局之间保留，构成"打金币→买装备→打更高难度"的循环。

- **金币**：击杀怪物获得（哥布林 5 / 飞眼 6 / 蘑菇 8 / 骷髅 15），乘以难度系数；击杀点弹出金色 `+N` 飘字。
- **经验与等级**：击杀得经验（8/10/12/25），升到下一级所需 = 60 + 40×(当前等级−1)；升级时主角头顶弹"升级 Lv.N！"飘字。等级用于解锁商城货架。
- **商城**（标题界面 / 结算界面进入）：

| 武器 | 解锁等级 | 价格 | 特点 |
|---|---|---|---|
| 手枪 | Lv.1 | 免费 | 伤害25 · 射速4（默认） |
| 冲锋枪 | Lv.2 | 150 | 伤害12 · 射速10 |
| 霰弹枪 | Lv.3 | 300 | 5 连珠扇形散射 |
| 狙击步枪 | Lv.5 | 600 | 伤害60 · 穿透 2 个敌人 |
| 加特林 | Lv.7 | 1200 | 伤害15 · 射速16 |

| 装备 | 解锁等级 | 价格 | 效果（购买后被动叠加） |
|---|---|---|---|
| 皮甲 | Lv.2 | 100 | 生命上限 +25 |
| 疾跑靴 | Lv.3 | 250 | 移速 +15% |
| 钢板甲 | Lv.4 | 400 | 生命上限 +50 |
| 快装弹夹 | Lv.5 | 500 | 射速 +20% |
| 守护护符 | Lv.6 | 800 | 受击无敌时间 +50% |

- 武器同时只能装备一把（购买自动装备，已购可点击切换）；装备为被动全部生效。
- 等级不够显示"Lv.N 解锁"，金币不够价格显示红色，不可购买。

### 4.6 难度选择（P0，已实装）

标题界面三选一（持久化记忆上次选择）：

| 难度 | 刷怪间隔 | 怪物血量 | 怪物伤害 | 金币收益 |
|---|---|---|---|---|
| 简单 | ×1.4（更慢） | ×0.8 | ×0.7 | ×1.0 |
| 普通 | ×1.0 | ×1.0 | ×1.0 | ×1.2 |
| 困难 | ×0.7（更快） | ×1.4 | ×1.4 | ×1.6 |

高难度高收益，鼓励买齐装备后挑战困难。

### 4.7 UI / HUD（P0）

- **战斗中**：左上角血条（含 当前/上限 数值）+ 金币数 + 等级与经验条；顶部中央存活计时；右上角击杀数与当前武器名。
- **开始界面**：标题 + 操作说明 + 难度三选 + 开始游戏 / 商城按钮 + 底部金币·等级·当前武器一览。
- **结算界面**：存活时间、击杀数、本局金币收益、总金币、历史最佳；按钮"再来一局"/"商城"（键盘 R / B）。
- **暂停**：P 键或触屏右上角按钮，暂停时画面变暗。

### 4.8 操作方式汇总（P0）

射击全自动（锁定最近敌人），玩家只控制移动。

**桌面（键盘）**

| 按键 | 功能 |
|---|---|
| ↑↓←→ / WASD | 八方向移动 |
| P | 暂停 / 恢复 |
| R | 结算界面重开 |

**手机（触屏）**

| 触控 | 功能 |
|---|---|
| 任意位置按住拖动 | 动态虚拟摇杆：按下处为原点，拖动方向 = 移动方向（360° 自由） |
| 右上角暂停图标 | 暂停 / 恢复 |
| 结算界面"再来一局"按钮 | 重开 |

### 4.9 移动端触屏与适配（P0）

- **视口适配**：游戏逻辑分辨率固定 960×540，canvas 等比缩放铺满可用视口（不足处留底色边）；横竖屏均可玩，横屏体验最佳。
- **防误触**：`<meta name="viewport">` 禁用缩放；canvas 设 `touch-action: none` 阻止页面滚动/双击放大；阻止长按弹出系统菜单。
- **输入统一**：键盘与触屏统一走 Pointer Events 抽象成"移动向量 + 开火布尔"两个输入信号，游戏逻辑不感知输入来源；必须支持多点触控（左手摇杆 + 右手开火同时按）。
- **虚拟控件显隐**：检测到触屏（`pointerdown` 的 pointerType 为 touch）才显示摇杆/按钮，桌面不显示。
- **性能**：中端手机稳定 60fps；移动端同屏怪物上限降为 30（配置表按设备区分）。

## 6. 技术方案

- **栈**：原生 HTML5 Canvas + JavaScript，无构建工具、无第三方库；requestAnimationFrame 主循环与输入处理复用 sprite_hero 经验。主角为纯代码绘制，**无图片资源依赖，双击 index.html 即玩（无跨域问题）**。
- **结构**：
  ```
  monster_arena/
  ├── index.html
  ├── server.js            # 本地预览静态服务器（可选）
  ├── docs/PRD.md          # 本文档
  └── js/
      ├── config.js        # 数值配置表（难度曲线/属性/武器/移动端差异）
      ├── stickman.js      # 火柴人程序化绘制（待机/走路/射击姿态）
      ├── input.js         # 输入抽象：键盘 + 触屏虚拟摇杆/按钮 → 移动向量+开火信号
      └── main.js          # 游戏主逻辑（状态机：title/playing/paused/gameover）
  ```
- **性能预算**：桌面同屏 ≤40 怪、移动端 ≤30 怪 + ≤100 子弹 + 飘字粒子，60fps；碰撞为 O(n×m) 圆检测（40×100=4000 次/帧），无需空间分区。
- **兼容目标**：近两年主流浏览器（Chrome/Safari/Edge/微信内置浏览器），iOS Safari 与安卓 Chrome 为移动端基准。

## 7. 部署与分享（P0）

- **形态**：纯静态站点（HTML+JS，无后端、无数据库），任意静态托管即可运行。
- **首选方案：GitHub Pages**——免费、自带 HTTPS、域名稳定（`https://<用户名>.github.io/monster_arena/`）；备选 Vercel / Netlify / Cloudflare Pages（效果等同，部署更快）。
- **流程**：本地 git 仓库 → 推送 GitHub → 开启 Pages → 获得公网链接 → 微信/任意渠道把链接发给朋友，对方手机或电脑浏览器打开即玩，无需安装。
- **更新**：改完代码 push 即自动重新发布（分钟级生效）。
- **隐私与数据**：无账号、无采集；最高纪录仅存玩家本机 localStorage。
- **（P2 备选）PWA**：加 manifest + service worker，支持"添加到主屏幕"与离线游玩。

## 9. MVP 验收标准

1. 双击 index.html（或本地服务器）即可游玩，无控制台报错。
2. 开始 → 战斗 → 死亡 → 结算 → 重开，闭环无卡死。
3. 怪物持续从屏幕外四周刷出并追踪主角，难度随时间可感知地上升。
4. 子弹能杀怪、怪能伤人，无敌帧与伤害冷却生效（不会一瞬间暴毙）；边走边打手感顺畅。
5. HUD 三要素（血条/计时/击杀数）实时正确。
6. 中途存活 2 分钟以上时帧率稳定（无明显卡顿，含中端手机）。
7. 手机浏览器（iOS Safari / 安卓 Chrome）打开链接：虚拟摇杆移动、攻击按钮连发、摇杆与按钮可同时操作，页面不滚动不缩放。
8. 游戏已部署公网，任何人收到链接后打开即玩；本地改动 push 后线上分钟级更新。

## 12. 大地图世界（v0.6 已实装）

- **地形**：Tiny Swords 素材包（Pixel Frog，免费授权，见 assets/tiny_swords/CREDITS.md）。水面铺底 → 沙滩层 → 草地层双层自动拼接（3×3 圆角块 + 单行/列/孤立块），海岸线带 8 帧动态泡沫、海面散布动画礁石。
- **世界尺寸**：3200×1920（50×30 格，64px/格），固定种子生成，每次进入布局一致：主岛 + 四座卫星沙洲，草地大陆上留沙滩环。
- **可行走性**：水面不可走——主角/怪物移动按轴向滑动判定，击退也不会把怪推下海；怪物只在主角周围环形区域内的陆地刷新。
- **场景**：动态松树 ×18、城堡 ×1、茅草屋 ×3、哨塔 ×2、吃草的羊 ×4、稻草人 ×2（全部与角色一起按 y 排序，可绕到建筑后面）；草地散布蘑菇/灌木，沙滩散布石头/骸骨。
