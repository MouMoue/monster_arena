# Tiny Swords

- 作者：Pixel Frog
- 官方页面：https://pixelfrog-assets.itch.io/tiny-swords
- 许可：免费素材包（Free Pack），可用于个人及商业项目，可修改；不要求署名；禁止转售或二次打包分发素材本身
- 网格：64×64 px，动画 10fps（100ms/帧）

## 本目录内容

完整免费包的 PNG 部分（197 张），目录名已转为小写下划线以适配 Web 路径，文件名保持官方原名：

- `terrain/ground/`：Tilemap_Flat（平地草/沙混合图块）、Tilemap_Elevation（高地+悬崖）、Shadows（高层投影）
- `terrain/water/`：水面、拍岸泡沫动画（foam）、礁石动画（rocks）
- `terrain/bridge/`：木桥
- `deco/`：18 种地图装饰（草丛、蘑菇、石头、骨头等）
- `factions/`：骑士与哥布林两阵营单位/建筑（雪碧图）
- `resources/`：金矿、羊、树、资源掉落物
- `effects/`、`ui/`：爆炸/火焰特效、按钮/图标/旗帜等界面元素
